Privacy Policy

Last updated: 1 November 2026

"Told by Things" is a small, private tool that creates short educational videos about inventions and uploads them to the Told by Things YouTube channel. It is operated by the channel owner and used only by the channel owner.

What the tool accesses

The tool uses Google's OAuth sign-in with a single permission: https://www.googleapis.com/auth/youtube.upload. This permission is used only to upload videos, with their title, description and tags, to the channel owner's own YouTube channel. The tool does not read, change or delete any other YouTube data, and it does not access Gmail, Drive, contacts or any other Google service.

What is stored

The sign-in token is stored only on the channel owner's own computer, in a file readable only by that user. It is not sent to anyone else. No data about viewers, subscribers or any other people is collected, stored or shared by this tool.

Third-party services

Video scripts are written with the Anthropic Claude API and narration is generated with a text-to-speech service. These services receive only the text of the video script, never Google account data.

Google API Services User Data Policy

The use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not sold, not used for advertising and not transferred to third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Viewers of the YouTube channel

Watching the channel's videos on YouTube is covered by Google's Privacy Policy. This tool does not receive any information about viewers.
